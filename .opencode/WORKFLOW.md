Use this repo as a reusable OpenCode starter.

Core rules:

- Keep each feature change to one small, testable slice.
- Plan before editing files.
- Test before finalizing.
- Review the diff before calling the work done.
- Say clearly when tests were not available or not run.
- Prefer modifying existing patterns over inventing new abstractions.
- Do not refactor unrelated code in the same change.

When you are unsure, shrink the slice instead of expanding the patch.
